# ADR-004 - Adocao de NestJS no backend

Data: 21/04/2026
Status: Aceita

## Contexto
O projeto precisava de produtividade com padrao de modulo, injecao de dependencia e suporte a testes.

## Decisao
Adotar NestJS como framework principal do backend.

## Consequencias
- Positivas: estrutura modular, integracao com Swagger e testes facilitados.
- Negativas: dependencia de convencoes do framework.
