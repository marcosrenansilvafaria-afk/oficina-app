# ADR-009 - Versionamento de API

Data: 21/04/2026
Status: Proposta

## Contexto
A evolucao de contratos pode quebrar consumidores sem estrategia de versao.

## Decisao
Documentar estrategia de versionamento explicito de API para evolucao controlada.

## Consequencias
- Positivas: menor risco de quebra para clientes da API.
- Negativas: aumento de manutencao quando multiplas versoes coexistirem.
